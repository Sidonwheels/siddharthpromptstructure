What is a prompt?

A prompt is the instruction you give an AI. Think of the AI as a fast, well-read assistant that knows nothing about your situation until you tell it.

Weak prompt

"Write about dogs."

Which dogs? For whom? How long? The AI has to guess.

Strong prompt

"Write a friendly 150-word Instagram caption for a rescue shelter, with 3 reasons to adopt."

Practice: run both prompts in any AI tool and compare the answers.

How AI reads your prompt

  • It predicts the most likely next words from patterns it has learned.
  • It only sees what you type, plus the conversation so far.
  • It can sound confident and still be wrong.
  • Clearer input leads to better output.
You▶Prompt▶AI model▶Output▶You review

The last step is the one most people skip. You are always the editor.

The framework: Task, Context, References, Evaluate, Iterate

T

Task: say exactly what you want done.

C

Context: who it is for, why, and the limits.

R

References: show an example of what good looks like.

E

Evaluate: check the answer before you use it.

I

Iterate: refine with follow-ups instead of starting over.

Memory trick: Thoughtfully Create Really Excellent Inputs4

TTask

Start with a strong verb. Add a persona (who the AI acts as) and a format (what the answer looks like).

Persona + Action + Format

"You are a career coach. Write a LinkedIn headline for a fresher in data analytics. Give 5 options in a numbered list, under 12 words each."

  • Good verbs: write, summarise, compare, explain, plan, rewrite.
  • One clear job per prompt works best.
Practice: turn "help with my resume" into a task with a persona and a format.
Prompt Engineering Basics | Siddharth Bhalla5

CContext

Context is everything the AI cannot guess. Cover these four:

  • Audience: college freshers, busy managers
  • Goal: why you need this
  • Constraints: length, deadline, budget
  • Tone: warm, formal, playful

"Explain what an API is. Audience: first-year B.Com students with no tech background. Goal: a 2-minute intro for a workshop. Tone: friendly, with one everyday analogy."

Practice: ask for the same explanation for a child, then for a CEO. Notice the shift.
Prompt Engineering Basics | Siddharth Bhalla6

RReferences

Show, don't just tell. One or two examples teach style faster than a paragraph of rules. This is called few-shot prompting.

"Here are two taglines I like:
1. 'Fuel your day, one sip at a time.'
2. 'Brewed slow. Enjoyed fast.'
Write 3 new taglines for a mountain homestay in the same style."

  • Examples can be text, a table, or a layout you want copied.
  • Never paste private or confidential material into a public AI tool.
Prompt Engineering Basics | Siddharth Bhalla7

EEvaluate

AI can invent facts, numbers, and links. This is called a hallucination. Check every output against this list:

  • Accurate: are the facts verified?
  • Relevant: does it answer my task?
  • Complete: is anything missing?
  • Tone: does it sound like me?
  • Safe: nothing private or biased?
  • Useful: can I use it as is?
Practice: ask an AI for "3 statistics about remote work", then verify each one with a trusted source.

IIterate

Your first prompt is a draft. Keep the chat going and steer it, like giving feedback to a colleague.

Putting it all together

Before

"Make a workshop plan on AI."

After

Task: You are a corporate trainer. Create a 60-minute workshop plan on prompt engineering.
Context: 30 college freshers, no tech background; the goal is to write a good prompt by the end.
Reference: use this layout: Time | Activity | Outcome.
Format: a table, then 3 practice exercises.

Then evaluate the plan and iterate: "Add a 5-minute icebreaker."

One framework, any tool

ChatGPT

General-purpose assistant. Good for drafting, brainstorming, and quick Q&A.

Claude

Strong with long documents, careful writing, and detailed instructions.

Gemini

Works closely with Google apps such as Docs, Sheets, and Gmail.

Tools update often, but the framework stays the same.

Practice: send one prompt to all three. Compare accuracy, tone, and structure, then note which suited the task best.

Your turn: 15-minute exercise

  1. Pick one real task from your week.
  2. Write a prompt using Task, Context, and References.
  3. Run it, then evaluate with the checklist.
  4. Iterate twice and save your best version.

Cheat sheet

Task = verb + persona + format. Context = audience, goal, limits, tone. References = 1 to 2 examples. Evaluate = verify facts. Iterate = refine, don't restart.
