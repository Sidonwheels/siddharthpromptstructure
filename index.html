Rule of the class:
we learn AI by using it.
1

1. What is a prompt?

A prompt is the instruction you give an AI. Think of the AI as a very fast intern: widely read, eager, but it knows nothing about your situation until you say so.

Weak prompt

"Write about dogs."

Which dogs? For whom? How long? The AI has to guess.

Strong prompt

"Write a friendly 150-word Instagram caption for a rescue shelter, with 3 reasons to adopt."

Try it: run both in any AI tool and compare the answers.
2

2. How AI reads your prompt

  • It predicts the most likely next words from patterns it learned.
  • It sees only what you type plus the chat so far.
  • It can sound confident and still be wrong.
  • Clearer input gives better output.
You→Prompt→AI model→Output→You review

The last step is the one people skip. You are always the editor.

3

3. The 5-step framework: T C R E I

Memory trick: Thoughtfully Create Really Excellent Inputs

T

Task: say exactly what you want done.

C

Context: who it is for, why, and the limits.

R

References: show an example of what good looks like.

E

Evaluate: check the answer before you use it.

I

Iterate: refine with follow-ups instead of starting over.

4

T is for Task

Start with a strong verb. Add a persona (who the AI should act as) and a format (what the answer looks like).

[Persona] + [Action] + [Format]

"You are a career coach. Write a LinkedIn headline for a fresher in data analytics. Give 5 options in a numbered list, under 12 words each."

  • Good verbs: write, summarise, compare, explain, plan, rewrite.
  • One clear job per prompt works best.
Try it: turn "help with my resume" into a task with persona and format.
5

C is for Context

Context is everything the AI cannot guess. Cover these four:

  • Audience: college freshers, busy managers
  • Goal: why you need this
  • Constraints: length, deadline, budget
  • Tone: warm, formal, playful

"Explain what an API is. Audience: first-year B.Com students with no tech background. Goal: a 2-minute intro for a workshop. Tone: friendly, with one everyday analogy."

Try it: ask for the same explanation for a child, then for a CEO. Notice the shift.
6

R is for References

Show, don't just tell. One or two examples teach style faster than a paragraph of rules. (Pros call this few-shot prompting.)

"Here are two taglines I like:
1. 'Fuel your day, one sip at a time.'
2. 'Brewed slow. Enjoyed fast.'
Write 3 new taglines for a mountain homestay in the same style."

  • Examples can be text, a table, or a format you want copied.
  • Never paste private or confidential material into a public AI tool.
7

E is for Evaluate

AI can invent facts, numbers, and links (this is called a hallucination). Check every output with this list:

  • ☐ Accurate: are facts verified?
  • ☐ Relevant: does it answer my task?
  • ☐ Complete: is anything missing?
  • ☐ Tone: does it sound like me?
  • ☐ Safe: nothing private or biased?
  • ☐ Useful: can I use it as is?
Try it: ask an AI for "3 statistics about remote work", then verify each one with a trusted source.
Trust,
then verify.
8

I is for Iterate

Your first prompt is a draft. Keep the chat going and steer it, like giving feedback to a colleague.

Prompt→Output→Evaluate→Refine↺
If the answer is…Say…
Too long"Cut this to 100 words."
Too complex"Explain it like I'm 15."
Too generic"Add a real example from retail."
Not enough"Give 3 more options, different tone."
Unsure what is missing"What would make this stronger?"
9

Putting it together

Before

"Make a workshop plan on AI."

After (T C R E I)

Task: You are a corporate trainer. Create a 60-minute workshop plan on prompt engineering.
Context: 30 college freshers, no tech background, goal is to write a good prompt by the end.
Reference: follow this layout: Time | Activity | Outcome.
Format: table, then 3 practice exercises.

Then evaluate the plan and iterate: "Add a 5-minute icebreaker."

4 techniques worth knowing

TechniqueWhat it doesExample
Role promptingSets expertise and viewpoint"Act as a financial analyst…"
Few-shotTeaches style with examples"Here are 2 samples. Write a third."
Step by stepImproves reasoning and maths"Solve this and show each step."
Format controlShapes the structure"Answer as a table with 3 columns."
Try it: combine two techniques in one prompt.

One framework, any tool

ChatGPT

General-purpose assistant. Good for drafting, brainstorming, and quick Q&A.

Claude

Strong at long documents, careful writing, and following detailed instructions.

Gemini

Works closely with Google apps like Docs, Sheets, and Gmail.

Tools update often, but the framework stays the same.

Try it: send one T C R E I prompt to all three. Compare accuracy, tone, and structure, then note which suited the task.

13

Common mistakes and fixes

MistakeFix
Too vagueAdd audience, goal, and length.
Five tasks in one promptSplit into steps; one job at a time.
No format askedSay table, bullets, or word count.
Trusting blindlyVerify facts, figures, and links.
Sharing private dataRemove names, numbers, and company secrets first.
Giving up after one tryIterate at least twice.
